FAQ & Contact

How much is collection?

10k-20k/month. Pay only licensed collector with ID.

What if pickup is missed?

Report on Report page. You get code "CWL-2026-00125" to track.

What if point is full?

Don't dump outside. Report overflowing bin. Use nearest other point.

Is my photo public?

No. Only authorized staff see it. Privacy protected.
